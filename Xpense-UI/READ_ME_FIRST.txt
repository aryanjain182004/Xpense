XPENSE UI — APK BUILD ZIP
=========================

1. Open the file ".env" in this folder.
2. Replace YOUR-XPENSE-API with your real Render backend host.
   Example: EXPO_PUBLIC_API_URL=https://xpense-api-abc123.onrender.com

3. Give this folder to your friend (or send the zip).

4. Your friend follows BUILD_ANDROID.md (npm install → eas login → eas build).

Backend on Render must have:
  FRONTEND_URL=xpenseui://
